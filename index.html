# Ingrid · Design System

The central reference for how Ingrid looks, moves and reads.

## 1. Identity and feel

**The feel in one line.** A quiet, light, hairline-drawn control room wrapped around a dark satellite map, where color is rare and always means something.

**Five words.** Calm. Precise. Operational. Dense-but-airy. Honest.

## 2. Principles and hard rules

- Use only CSS variables for color in UI chrome.
- Fonts: Geist (400, 500) and Geist Mono (400).
- Radius is `var(--radius)` (4px).
- Numbers use `font-variant-numeric: tabular-nums` and the mono face.
- Respect `prefers-reduced-motion`.

## 7. Motion

```css
--ease-enter: cubic-bezier(.16, 1, .3, 1);   /* things arrive easing out */
--ease-exit:  cubic-bezier(.4, 0, 1, 1);     /* things leave easing in */
--t-pop: 200ms;  --t-pop-out: 160ms;         /* dropdowns, popovers, drawer */
--t-panel: 220ms; --t-panel-out: 176ms;      /* docked panels, detail, export */
```

**The rule:** every exit is 20% shorter than its entrance.

## 13. Writing and copy

Short, literal, operational. Say what is happening and what the person can do.

- **Buttons are verb phrases:** Send to maintenance, Keep running, Show on map.
- **IDs and names:** trucks `HT-01`…`HT-06`; pits `N4`, `N4W`, `N5`.
- **Numbers carry units** (`t`, `km/h`, `min`, `s`, `%`, `m`).
